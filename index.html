Geno-1
  • Click the canvas to play a note. Mouse position shapes the sound.

Keys

  • A..G: set root note
  • 1..7: set mode
  • 8,9,0: set tuning (19/24/31‑TET) • P: C Major Pentatonic
  • R: new sequence
  • T: random root + mode
  • Space: pause/resume
  • ,/.: detune ±50¢ (Shift for ±10¢)
  • /: reset detune to 0¢
  • Enter/Esc: full/exit screen
  • ←/→: tempo • ↑/↓: volume
  • M: mute/unmute master

Modes (1..7)

  • 1: Ionian (major)
  • 2: Dorian
  • 3: Phrygian
  • 4: Lydian
  • 5: Mixolydian
  • 6: Aeolian (natural minor)
  • 7: Locrian

Tunings (8,9,0)

  • 8: 19‑TET pentatonic
  • 9: 24‑TET pentatonic
  • 0: 31‑TET pentatonic
  • P: C Major Pentatonic (default)
